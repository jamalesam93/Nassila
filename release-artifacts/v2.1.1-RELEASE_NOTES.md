# Nassila v2.1.1 — Arabic OCR fidelity

**Codename:** Arabic OCR fidelity · دقة OCR العربي  
**Shipped:** 2026-10-23  
**Installer:** cut with `npm run build:win` when publishing (`Nassila Setup 2.1.1.exe`). Not attached in this commit.

### Fixed

- **Arabic OCR line order** — each recognized line is reversed on its own. A whole-page reversal put lines bottom-to-top.
- **Legacy-encoded Arabic text layers** are flagged and sent to OCR instead of being parsed as bibliography text.
- **Arabic verbatim quotes** tolerate diacritics, alef/ya/ta-marbuta variants, Arabic-Indic digits, and edge punctuation.

### Added

- **Optional Indra OCR download** — Settings → Local models fetches about 14 MB. The app runs those weights itself. No Python. Once installed, Indra reads Arabic scans, and PaddleOCR reads any page Indra cannot. Without the download, Arabic scans stay on the packaged Paddle adapter. The weights are not bundled.
- Evaluation evidence (not a user claim): the in-app port matched the Python package on 84 reference-valid pages (median CER 0.067, 76 wins vs Paddle). Raw run: `E:\Antigravity Projects\NassilaAGY\ocr-ab`.

### Changed

- Native PDF inspection is `@firecrawl/pdf-inspector` 1.25.2. Text-only PDFs do not load OCR models.
- The Windows package no longer ships unused native libraries for other operating systems.

### Unchanged

- **Arabic L3 grounding stays unvalidated.** 2.2.0 Sanad Arabic is paused for budget. Sanad on the Hub remains **FT-6** (v119).
