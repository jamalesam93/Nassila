# Nassila v1.10.0 — Masdar Papers

**Codename:** Masdar Papers · أوراق مصدر  
**Shipped:** 2026-08-22  
**Installer:** Windows x64 NSIS — `Nassila Setup 1.10.0.exe`

> Sanad **FT-6** shipped Hub-only on 2026-08-21 — there is **no 1.9.0 installer**; this is the next app cut.

### Added

- **Bibliography dedupe (#19)** — duplicate references (same DOI, else same normalized title + year) collapse into one audit finding; citation sites from both numbers stay attached via key aliases. Title-only look-alikes are flagged **ambiguous**, never silently merged; Sharh-lite shows the dedupe outcome when it did work.
- **Attach papers by folder (#19)** — point the Manuscript loop at a folder of source PDFs: Nassila scans it recursively (≤200 files, ≤50 MB each), matches each PDF to your references by first-page DOI or title, and after your confirmation attaches only the matched references and re-audits exactly those entries.
- **Targeted multi-reference re-audit (#19)** — `bibKeyFilter` widened to a list so one run re-grounds exactly the selected references while other findings stay in place. Older saved sessions keep working (legacy single-key filters normalize).

### Changed

- **Raqim Resolve works again for titles and URLs (#20)** — URL rows previously short-circuited to a placeholder grey-web card and moderate title matches were silently dropped by the confidence threshold. Registry title search now always runs for URLs, and non-exact candidates score `min(0.8, 0.24 + 0.58 × similarity)` against the 0.42 threshold — correct papers with subtitle/punctuation variants surface again.
- **Resolve panel field prefill parity (#20)** — switching between DOI / PMID / PMCID / URL / title auto-copies that value from the row into the search box without clobbering user edits; Verify-row syncs kind + key to the identifier actually searched.
- **Honest Wayback links (#18)** — the unconditional `[Wayback ↗]` on every URL row is gone. The Resolve panel queries snapshot availability in main (`registry:checkWaybackAvailability`) and renders a direct-to-snapshot link only when one exists; archive lookups always target the page URL, never a doi.org fallback.
