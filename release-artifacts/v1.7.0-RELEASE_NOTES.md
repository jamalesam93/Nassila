# Nassila v1.7.0 — Integrity Bundle

**Codename:** Integrity Bundle · حزمة النزاهة  
**Shipped:** 2026-08-10  
**Installer:** Windows x64 NSIS — `Nassila Setup 1.7.0.exe`

### Added

- **Structured DOCX manuscript import (Maktab Route C)** — manuscript DOCX files now import through `mammoth.convertToHtml` instead of flat raw text: paragraph blocks are preserved and real Word heading levels (`Heading1..6`) are surfaced as a segmentation side-channel (`src/engine/maktab/docx-extract.ts`). Bibliography `parseDocx` is untouched. Import warnings surface in a dismissible review notice (EN/AR).
- **Dirty-close warning** — closing the window with unsaved work now asks for confirmation before the session is lost. Main-process close guard (`src/main/app-close-guard.ts`, channels `app:close-requested` / `app:confirm-close`) with the renderer reusing the existing confirm dialog (EN/AR).
- **Preflight+ mapping breakdown** — Sharh-lite now shows matched / ambiguous / unmatched citation counts alongside the coverage percentage (EN/AR).
- **Gamalix credit line** — the About dialog now shows "Made by Gamalix" (EN/AR).

### Trust & packaging hardening (verified shipped)

- **Audit rate limiting under concurrency** — `DEFAULT_AUDIT_CONCURRENCY` semaphore pools (registry 3 / source 2 / llm 1) plus 429/503 retry backoff.
- **Mid-LLM cancel** — `AbortSignal` is threaded through `services.llmChat` → `executeLlmChat` → `fetch`, so cancel stops the model call mid-flight.
- **Deterministic supported-claim downgrade guardrail** — an L3 `supported` verdict without a verbatim quote found in the source excerpt is downgraded to `weak`.
- **Packaged parity + CI smoke gates** — registry/align/OA/LLM all main-process; `package-windows` CI runs `probe:ocr` + `probe:ocr:golden` on every release train.
