# Nassila v1.6.0 — Maktab Loop

**Codename:** Maktab Loop · حلقة المخطوطة  
**Shipped:** 2026-08-05  
**Installer:** Windows x64 NSIS — `Nassila Setup 1.6.0.exe`

### Added

- **Maktab OCR golden fixtures** — generated PDF suite (text + image/scan pages) with byte-level goldens and a real-Tesseract OCR probe (`scripts/probe-ocr-golden.mjs`) wired into the Windows CI packaging job.
- **Cache controls** — Settings → Storage: inspect and clear the source-artifact and Maktab extraction caches (new `sourceArtifactCacheInfo`/`clearSourceArtifactCache` and `maktab:extractionCacheInfo`/`maktab:clearExtractionCache` IPC).
- **Review-after-import banner** — dismissible needsReview notice in the loop when PDF import extraction needs human attention.
- **Richer deterministic Sharh summaries** — aggregate `coverageBreakdown`/`passageBuckets`/`claimBreakdownByFinding` in `sharh-lite.ts`, localized headline + per-finding copy (`sharh-copy.ts`), expanded SharhLitePanel (EN/AR).
- **Masdar source-PDF attach verified** — attach a local PDF for any cited source and re-ground just that reference (single-reference re-audit), with in-flight attach guards.
- **RTL acceptance pass** — swept physical-direction strays to logical utilities across panels, settings, and tooltip chrome.

### Fixed

- Reconcile stale "local-PDF attach planned" wording across `OUROBOROS_CONTEXT`, `PRODUCT`, `OUROBOROS`, and `USER_GUIDE` — per-reference PDF attach and single-reference re-audit are live.
